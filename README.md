## 🔎 Arama Algoritmaları
- Linear Search → O(n)
- Binary Search → O(log n)

---

## 🔁 Sıralama Algoritmaları
- Bubble Sort → O(n²)
- Selection Sort → O(n²)
- Insertion Sort → O(n²)
- Merge Sort → O(n log n)
- Quick Sort → O(n log n)

## 🎤 Proje Anlatımı

Bu projede temel arama ve sıralama algoritmalarını Python dili ile gerçekleştirdim.

İlk olarak arama algoritmalarından Linear Search ve Binary Search kullandım. 
Linear Search algoritması, liste içerisindeki elemanları tek tek kontrol ederek arama yapar ve zaman karmaşıklığı O(n)’dir. 
Binary Search ise sıralı listelerde çalışır ve listeyi ortadan bölerek arama yaptığı için daha hızlıdır. Bunun zaman karmaşıklığı O(log n)’dir.

Sıralama algoritmaları kısmında ise Bubble Sort, Selection Sort, Insertion Sort, Merge Sort ve Quick Sort algoritmalarını kullandım. 
Bubble Sort algoritması komşu elemanları karşılaştırarak sıralama yapar. 
Selection Sort en küçük elemanı seçerek sıralar. 
Insertion Sort ise elemanları uygun konuma yerleştirerek çalışır.

Merge Sort algoritması böl ve yönet mantığıyla çalışır ve O(n log n) karmaşıklığa sahiptir. 
Quick Sort ise pivot eleman seçerek diziyi parçalara ayırır ve ortalama durumda yine O(n log n) performans gösterir.

Bu proje sayesinde algoritmaların çalışma mantığını ve aralarındaki performans farklarını öğrenmiş oldum.
